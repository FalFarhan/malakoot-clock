Adhan recordings for ملكوت (Earth Clock)

Drop Ablaj's files here, then rebuild the site / phone app:

  default.mp3   Required. Used for every prayer, and for Fajr when fajr.mp3 is absent.
  fajr.mp3      Optional. Used only for the Fajr alert. If the file is missing, default.mp3 plays.

Also copy the same default.mp3 over  ../adhan.mp3  (legacy path, still referenced as a fallback alias).

Formats: MP3 (or another browser-playable format with the .mp3 name). Keep each file to a reasonable size (a few MB).
After replacing a file, run a new web build (and a new Android AAB if the phone app should ship the new sound).
